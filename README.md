# Portal Resmi PGRI Cabang Matraman — Vercel Iframe Wrapper

Folder ini merupakan **Vercel Iframe Wrapper** resmi untuk website portal PGRI Cabang Matraman yang terhubung langsung dengan backend Google Apps Script.

---

## 🚀 Fitur & Spesifikasi

- **Instant Fullscreen Viewport**: 100vw × 100dvh tanpa animasi loading di awal.
- **Dukungan Perangkat Keras & Fitur Penuh**:
  - Kamera & Mikrofon
  - Geolocation
  - Clipboard Read/Write
  - Fullscreen & Download Berkas
- **Optimasi Mobile & SEO**:
  - Meta tags, OpenGraph preview, dan Favicon PGRI.
  - Penanganan anti-zoom ganda di Safari iOS.
- **Konfigurasi Vercel**: `vercel.json` dengan `cleanUrls` dan *permissions-policy* mutakhir.

## 📦 Sinkronisasi ke GitHub

Untuk memperbarui dan mengirim perubahan ke repository GitHub resmi:

1. **Menggunakan Double Click (Windows)**:
   - Jalankan `push_to_github.bat`
2. **Menggunakan PowerShell**:
   - Jalankan `powershell -ExecutionPolicy Bypass -File .\push_to_github.ps1`
